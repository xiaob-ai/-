## 📄 介绍

原创低仿知乎vue3加nestjs练习项目，页面清新大气，项目文件组织结构清晰，基础功能完善，细节丰富，采用websocket实现基础的实时通信私信功能！


 1.登录及注册
 
 2.话题发布，与话题排行榜查看（包含跳转至话题相关问题界面）
 
 3.提问题（可筛选添加与之相关话题）
 
 4.选择问题回答（可根据关键词或话题进行筛选问题）
 
 5.首页查看回答
 
 6.给相关回答点赞/点踩/评论
 
 7.查看问题相关回答详细页（可关注相关问题及底下回答的作者）
 
 8.查看点赞用户列表并可点击图标访问用户主页 
 
 9.访问自己或其他用户主页，可查看用户相关回答/提问/关注/粉丝信息
 
 10.可在他人主页点击按钮进入独立私聊界面，会自动获取先前会话列表及未读消息预览
 
 11.进入相应列表后获得全部消息，并且能够通过websocket进行实时通信
 
 12.可对个人信息和头像进行编辑

## 👨‍💻 技术亮点

1. **前后端分离架构** - 清晰的职责划分，便于维护和扩展
2. **TypeScript 全栈类型安全** - 从前端到后端的完整类型系统
3. **实时通信** - 基于 Socket.IO 的即时聊天功能
4. **模块化设计** - NestJS 模块化 + Vue 组件化
5. **自动化数据库同步** - TypeORM synchronize 自动建表
6. **统一异常处理** - 全局过滤器与拦截器
7. **持久化状态管理** - Pinia 数据持久化
8. **现代化 UI** - Element Plus + Tailwind CSS 组合
